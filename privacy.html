Privacy policy

Last updated 14 November 2026

Underhood is a short-form video channel. This policy covers the Underhood website and "Underhood Publisher", the internal tool Underhood uses to publish its own videos and read its own channel statistics.

Who uses Underhood Publisher

Underhood Publisher is used only by Underhood to manage Underhood's own accounts on YouTube, Instagram and TikTok. It is not offered to the public, and no one else can sign in to it.

What data it accesses

  • YouTube (Google API Services): it uploads Underhood's videos, sets their titles, descriptions and thumbnails, and reads view and engagement statistics for Underhood's own channel.
  • Instagram and TikTok: it publishes Underhood's own posts and reads statistics for Underhood's own accounts.

It does not access, collect or store personal data about viewers or any other users. Statistics are aggregate figures provided by each platform.

How data is stored

Sign-in tokens and statistics are stored encrypted in Underhood's private cloud storage, used only to run the channel, and never sold, shared or used for advertising.

Google API Services

Underhood Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.

This website

This website uses no cookies, analytics or tracking.
